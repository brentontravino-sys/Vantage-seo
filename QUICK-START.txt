                           TO START DEVELOPMENT
================================================================================

Option 1 - Using the batch file (Windows - RECOMMENDED):
----------------------------------------------------------
  1. Open Command Prompt
  2. Navigate to: C:\Users\User\Downloads\Vantage-seo
  3. Run: start-dev.bat

Option 2 - Using npm (Windows/Mac/Linux):
----------------------------------------------------------
  1. Open terminal
  2. Navigate to project folder
  3. Run: npm run dev:full

Option 3 - Manually (two terminals):
----------------------------------------------------------
  Terminal 1: npm run mock-server    (Backend on port 3001)
  Terminal 2: npm run dev             (Frontend on port 5173)

================================================================================
                           TROUBLESHOOTING
================================================================================

  If you have issues:
  
  1. "Port already in use"
     - Run: npx kill-port 3001
     - Run: npx kill-port 5173
     - Then restart servers

  2. "Cannot find module"
     - Run: npm install

  3. "Frontend can't connect to API"
     - Check .env file has: VITE_API_BASE_URL=http://localhost:3001/api
     - Make sure mock server is running
